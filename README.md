# Celestial Cartography — 3D Horoscope App

Verified: `npm install`, `npx tsc -b`, and `npx vite build` all pass clean in this scaffold.

## Run it

This is now two apps: the Vite frontend and an Express backend that does the
real astrological math. Run both, in two terminals:

```bash
# Terminal 1 — backend (real ephemeris-based birth chart calculation)
cd server
npm install
cp .env.example .env
npm run dev          # http://localhost:4000

# Terminal 2 — frontend
npm install
cp .env.example .env  # VITE_API_URL=http://localhost:4000
npm run dev            # http://localhost:5173
```

├── src/

## Birth chart math — now real

The backend uses [`circular-natal-horoscope-js`](https://www.npmjs.com/package/circular-natal-horoscope-js),
a pure-JS ephemeris-based library (no binary Swiss Ephemeris dependency),
to compute the actual Sun, Moon, and Ascendant (Rising) sign from date,
time, and geocoded lat/long — verified in this build against a real
test case (June 15 1995, 14:30, Bengaluru → Sun in Gemini, correctly
computed Moon and Ascendant signs).

Two honesty notes surfaced in the UI itself, not buried in code comments:

- **No birth time given** → the API still returns a Rising sign (using
  noon as a default) but flags `approximateRising: true`, and the result
  panel tells the user to add a time for a precise reading.
- **Location resolution** happens via free-text geocoding — the resolved
  place name is shown under the results so users can tell if their city
  matched correctly.

### Why a backend at all

The Origin/Horoscope calculation itself is cheap enough to run in the
browser, but geocoding a free-text location needs a server-side call
(committing an API key to a bundled frontend is not great practice, and this
setup can swap in a paid/more precise geocoder later without touching the
client). Splitting it out also gives you a natural place to add caching,
auth, or swap the ephemeris library without a frontend redeploy.

## Extending

- **More signs of the zodiac wheel**: positions are generated by `wheelPosition()`
  in `zodiacData.ts` — add more entries and the ring geometry in
  `ZodiacWheel.tsx` will auto-connect them.
- **Replace shader glow with drei's built-in `<Sparkles />` or `<Trail />`**
  for a cheaper alternative if targeting low-end mobile GPUs.
- **Swap CameraControls easing**: `CameraRig.tsx` isolates the GSAP tween —
  change `ease: "power3.inOut"` or `duration` there without touching the rest
  of the 3D scene.
